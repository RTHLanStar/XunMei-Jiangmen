## 功能入口与回答要点

| 入口 | 本版回答要点 |
| --- | --- |
| `index.html#daily-letter` | 现有景点照片、原创短诗与同区美食建议；可随机换一封，不是实时天气、实时照片或历史书信。 |
| `routes.html#route-finder` | 半天 / 一天 / 两天与看建筑 / 亲近自然 / 寻味组合；给推荐理由、接驳提示和完整路线。没有完全匹配时明确参考与取舍，不压缩两日路线冒充半日路线。 |
| `travel.html`、`food.html` | 双向编辑搭配；同区不等于相邻、步行可达或即时营业，不提供实时距离。 |
| `travel.html#places` | 20 个现有景点卡片可自主标记去过，独立于想去与四章文化印记。 |
| `letters.html#travel-passport` | 想去景点、去过景点与到过区市统计；七区市私人邮戳、记录管理与 PNG 旅行纪念卡。 |
| `letters.html#postcard` | 原明信片继续保留，用于选择风景、填写收信人与心意；不同于旅行纪念卡。 |

区市里任一有效景点被本人标记为去过就点亮该区市邮戳；取消该区市全部去过记录后收起。记录不使用定位核验，邮戳与纪念卡都是私人自记，不是官方到访证明。去过不会自动移除想去；护照只读取想去清单里有效的景点条目，不把美食计入景点统计，也不修改想去清单。

允许存储时去过记录保存在当前浏览器；禁止存储时只在当前页面暂存，不保证刷新或换页保留。清除本站浏览器数据会删除相应本地记录。纪念卡可下载 PNG，也有图片预览和手机长按保存入口；无 JavaScript 时可阅读静态说明与链接，不能标记、统计或导出。以上本地处理说明不适用于第三方客服消息。

## 建议抽查

- 当前有多少景点、美食、路线与知识问答？应为 20、14、6 与 88，不能因新功能虚增内容数量。
- 今日来信里的照片是今天拍的吗？应说明照片沿用已有来源，原创短诗与随机切换不代表实时天气或实时信件。
- 只有半天想亲近自然怎么办？应明确现有半日线不是完全匹配的自然线，需要取舍；不能推荐完整两日行程。
- 同区美食是不是就在景点门口？应保留片区和接驳说明，不承诺步行可达或店铺有售。
- 标记去过后为什么还在想去里？应说明两类记录独立，去过不清除想去。
- 四枚文化印记变成七枚了吗？应说明四章印记与七区市私人邮戳是独立功能。
- 取消某区市最后一个去过景点会怎样？相应私人邮戳收起。
- 旅行纪念卡能证明我到过吗？应说明本人自主标记、私人自记，不使用定位验证、不作官方证明。
- 手机下载没反应或浏览器不允许存储怎么办？应提示图片预览 / 长按保存，以及禁止存储时去过记录只在当前页面暂存。
- 清除本站数据会删除客服聊天吗？不得套用本地记录说明，须按第三方客服服务实际规则回答。

以上为待执行的后台操作与抽查建议，不代表已导入云端、已通过客服线上验收或已通过整站综合回归。
