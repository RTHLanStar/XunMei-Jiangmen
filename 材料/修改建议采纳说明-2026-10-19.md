# 修改建议采纳说明

整理日期：2026-10-19。依据用户提供的《修改建议.md》逐项核对当前代码、素材记录与已保存验证结果。本文说明本轮选择及边界；是否构建、验证、打包成功，以本轮实际结果为准。

## 本轮采纳

| 建议 | 本轮处理与理由 |
| --- | --- |
| 把知识库接进网站 | 新增 `faq.html` 本地问答页，从现有知识库生成分类、关键词检索与静态答案。用户无需等待第三方客服即可查资料；离线打开完整目录也能阅读。问答为预写内容，不伪装联网 AI。 |
| 作品导览 | 新增 `tour.html`，用约 3 分钟的建议顺序串联短片、四章印记、明信片和旅行功能，帮助第一次打开作品的人找到重点；不设置强制计时或自动跳转。 |
| 分享元数据 | 为九页补独立标题、简介、分享图和 canonical，按实际 `/v2.2/` 部署基址生成。Open Graph 有助于支持它的平台识别页面，但不承诺微信或 QQ 卡片效果。 |
| 旅行页打印 | 为景点、美食、路线及站内问答补打印布局，保留筛选结果与来源，收起操作控件并改善纸面可读性。可在浏览器打印预览中选择页码。 |
| 焦点可见性 | 在已有按钮、链接和表单焦点样式之上补 `summary` 等控件的通用兜底；继续保留跳转链接、减少动效和无 JavaScript 阅读。 |
| 历史哈希 CSS 不进交付包 | 打包只选择当前 HTML 实际引用的哈希 CSS，避免把历史构建版本重复交付；工作目录中的历史源码保留。 |
| 文档与工程维护 | 更新 DESIGN、补 README、回核旧计划完成状态；新增 `build.py` 统一构建/静态验收/打包入口，`browser-runtime.cjs` 支持环境变量指定测试依赖。旧历史验证脚本不做无差别改写。 |

## 经核对，需要纠正的判断

- **“视频没有字幕轨”不符合当前文件。** `index.html` 已有指向 `assets/subtitles.vtt` 的中文字幕 `track`，短片也有画面字幕，本轮不重复挂轨。
- **“七页都没有跳至主内容”不符合当前文件。** 原七页各有 `class="skip"` 的跳转链接，目标包括文化探索、旅行指南、故事、明信片与创作说明。原 `style.css` 也已有链接、按钮、输入框、下拉框和文本域的 `:focus-visible`；本轮是补遗漏控件，不是从零添加。
- **“四章全用 Canvas 绘制”不符合当前实现。** `app.js` 通过 `new Image()` 加载章节 WebP，外层图像区域有随章节更新的可访问名称。Canvas 用在明信片、旅行纪念卡及部分效果，不需要给四章虚构一个并不存在的 Canvas 缺口。
- **“没导入云端知识库，所以客服一定报错”证据不足。** 尚未导入只能说明新版知识尚未同步，无法据此判断外部 SDK 的实际运行状态。用户指定的脚本继续保留，本地 FAQ 提供独立查询入口；本轮没有登录后台或导入云端。
- **“Git modified 说明交付 ZIP 不一致”不能成立。** 完整包脚本已生成 SHA-256 清单并逐文件核对，两个打包脚本也检查 ZIP CRC 和源文件字节。未提交代码与交付是否同步是两件事；本轮仍会在修改完成后重新打包核验。
- **“没有 package.json 就没有构建流程”不准确。** 网站运行无需前端打包器，但旅行页面、模块和合并样式已有 Python 生成流程。新增 README 和统一入口是把现有流程说明清楚。
- **“Open Graph 能直接保证微信分享卡片”不准确。** 当前为纯静态站点，没有后端签名的微信 JS-SDK 分享配置；只承诺生成规范页面元数据，不承诺特定平台展示。

## 本轮不改或暂缓

| 建议 | 处理理由 |
| --- | --- |
| 删除全局禁止右键 | 用户此前明确要求该行为，继续保留。旅行纪念卡预览已有图片保存例外；禁止右键不能当作版权防护。 |
| 批量删除旧 ZIP、视频中间文件 | 这些文件承载制作历史与回退版本，不能仅凭建议推定可删除。通过交付清单控制包内容，不破坏工作目录。 |
| PWA / service worker | 会增加缓存更新和 `/v2.2/` 范围管理成本，本轮优先保持普通静态托管和完整目录离线打开，不承诺浏览器自动离线缓存。 |
| 粤语或四邑话音频、竖版短片重剪 | 需要独立的语言核验、声音试听及画面重排。保留用户已确认的自然男声与 66 秒成片，不在一次网站维护中替换。 |
| 繁体 / 英文切换 | 涉及文化专名、事实文案与全部交互提示的一致性，需要独立翻译校核，不能只替换字形就宣称双语完成。 |
| 原创仿写历史侨批、陈皮“十年药”等文案 | 当前主题是当代原创来信；不冒充历史材料，也不加入未经核实的健康功效暗示。历史科普可在取得充分来源后另做。 |
| 新地图、乡音、信笺画廊、更多分享卡 | 暂缓增加新的交互层；先让已有内容更容易查找、导览和带走，保留现有明信片与旅行纪念卡。 |
| 自动填写报名信息、确认赛事渠道和期限 | 用户未提供新的正式身份与组织方确认信息，本轮不推断、不补造，也不根据建议文档自行执行报名或提交。 |

## 素材和交付边界

当前仍为 20 个景点条目、14 种美食、6 条编辑路线，新增功能不虚增内容数量。景点摄影、四章 AI 艺术图、4 张美食摄影参考及 10 张 AI 菜式示意继续按原记录区分。

陈少白故居、海口埠、歇马举人村、锦江温泉的 4 张官方配图仍为 `permission-not-confirmed`；本轮未获得或补造授权。陈皮村图继续保留完整画面、水印与“来源：罐头图库”，不把图库条件使用写成 CC 授权。DESIGN 删除了与现有实景图片相矛盾的“一律不使用第三方摄影”旧表述，改为按逐图许可、署名和修改条件维护。

只更新本地静态文件、说明、知识库及 ZIP，不发布在线预览、不上传虚拟主机、不导入云端客服。新的功能与文件数以本轮生成结果为准；历史验证记录仅作为已有能力的证据，不替代本轮回归。
