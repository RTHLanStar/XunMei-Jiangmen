## 浏览器回归（`verify-theme-ui.cjs`，全项通过）

- 主题解析：系统深色 → `data-theme=dark`、背景 `rgb(20,28,26)`；系统浅色 → `data-theme=light`、背景 `rgb(245,240,230)`；`meta#theme-color` 同步为 `#0f2824` / `#183d36`。
- 三态循环：跟随系统 → 固定一档 → 另一档固定 → 回到跟随系统，三次点击的 `aria-label` 各不相同；固定值写入 `localStorage['jiangmen-theme']` 并跨页保持。
- 首帧顺序：九页的内联主题脚本均位于样式表 `<link>` 之前，九页各有且仅有一个 `meta#theme-color` 与一个主题开关。
- 打印：`emulateMedia('print')` 下背景 `rgb(255,255,255)`、文字 `rgb(17,17,17)`。
- 布局：九页 × 320/375/768/1280/1440 五档宽度无横向溢出；`travel.html` 卡片列数在 1440px 为 3、1024px 为 2、640px 为 1；320px 下顶栏开关与品牌不重叠，命中区 44×44。
- 标题字阶：九页 h1 计算字号一致。
- 运行时：九页无 page error。

## 顺带修回的历史回归脚本

这些失败**不是本轮视觉改动引入**，而是更早的改动让脚本与产品行为脱节；本轮按当前设计更新了断言，脚本重新可用。产品行为一律不改，只改脚本。

| 脚本 | 脱节原因 | 处理 |
| --- | --- | --- |
| `verify-readability.cjs` | 首页 h1 自 2026-10-18 打字机改造后不再含直接文本，CDP 取字形返回空数组，「未使用自定义字体」误报 | 改为优先取 `h1 .hero-type-char` 取样节点 |
| `verify-collection-final.cjs` | 脚本假设第 4 枚印记收集后仍自动翻页，而 2026-10-19 的设计是集齐后展示完成面板、不翻页 | 改为断言完成面板可见且进度为 4 / 4 |
| `verify-web.cjs` | `#card-form button` 选择器过宽，命中提交 / 预览 / 分享三个按钮 | 收窄为 `#card-form button[type="submit"]` |
| `verify-offline.cjs` | 同上，离线导出明信片的断言卡在多匹配定位器上 | 同上 |
| `verify-media-polish.cjs` | 章图交叉淡入时长在 2026-10-19 已由 300ms 调整为 320ms，脚本仍断言 300 | 断言同步为 320，其余用例未动 |
| `verify-film-v2.cjs` | 短片改为点击后加载（`preload="none"` + `data-src`），脚本仍在首帧等待 `readyState>=1` | 先点击 `.film-play` 再等待元数据；66 秒 / 1080P / 25 条字幕等断言不变 |
| `verify-qa-coexist.cjs` | 在线客服只保留 Knocket 悬浮按钮（2026-10-19 起不再有页尾与问答页的内联在线入口，静态验收亦断言 `online-help.js` 不再交付），脚本仍在测已下线的内联入口 | 按当前契约重写：九页 SDK 各注入一次且位于 `</body>` 前、已下线模块不再出现、SDK 被拦截 / 延迟 / 关闭 JavaScript 时离线问答与版面仍完全可用 |

同时修掉一处真实的可读性回退：`今日来信` 的 eyebrow 固定 12px，低于站点移动端 13px 下限，现已回到 `--small-text` 体系。

## 收尾时发现并修掉的构建缺陷（本轮自身引入）

主题内联脚本与 `theme.js` 标签原先只在首次构建注入，构建脚本只清理旧的 `meta#theme-color`，**没有清理上一次注入的脚本**，因此每跑一次构建，4 个手写页面就多一份主题启动脚本与一份 `theme.js` 标签（本轮一度累积到各 4 份）。

- 修复：`build-travel-guide.py` 在注入前先剥离旧的 `jiangmen-theme` 内联脚本，并把 `theme` 加入脚本标签清理列表；重建后九页各恰好 1 份，顺序仍为 `meta#theme-color` → 内联脚本 → 样式表 `<link>`。
- 防回归：`verify-adopted-static.py` 新增断言——九页各恰好一个 `meta#theme-color`、一份主题启动脚本、一个 `theme.js` 标签。

## 已知约束（刻意保留）

- 照片与 AI 艺术画面不随主题翻转；明信片与旅行纪念卡的画布保持纸白纸面（实物隐喻）。
- 第三方 Knocket 悬浮按钮为蓝色且样式不在本站控制范围内，深色下依旧突兀，记录为已知约束，未做美化。
- 关闭 JavaScript 时页面保持浅色；`:root` 声明 `color-scheme: light`，浏览器不会对它做强制反色。
- 本轮未发布在线预览、未上传虚拟主机、未导入云端知识库。
